The model

STIsim is an agent-based modelling framework for simulating co-circulating sexually transmitted infections. Built on the Starsim architecture, it supports structured sexual networks, multiple co-transmitting infections (HIV, syphilis, chlamydia, gonorrhoea, trichomoniasis, BV, and others), risk-stratified populations, and a flexible intervention library spanning screening, testing, treatment, and prevention. It is implemented in pure Python, extensively tested and documented, and runs in seconds to minutes on a laptop.
